# SSGC Website - Cash Transfers Tracker

A React application to display cash transfer data from Google Sheets with PDF export functionality.

## Features

- Display cash transfer data from Google Sheets
- Styled table matching the original design
- PDF download functionality
- Responsive design

## Installation

1. Install dependencies:
```bash
npm install
```

## Development

Run the development server:
```bash
npm run dev
```

The app will be available at `http://localhost:5173`

## Build

Build for production:
```bash
npm run build
```

## Technologies Used

- React 18
- Vite
- Axios (for fetching Google Sheets data)
- jsPDF & html2canvas (for PDF generation)
