# Quick Start Guide

## 🚀 Fastest Way to Get Started (2 minutes!)

### Option 1: Google Sheets (EASIEST - Recommended!)

1. **Convert Excel to Google Sheets:**
   - Open `SSGC_Cash_Transfers.xlsx` in Google Drive
   - Right-click → "Open with" → "Google Sheets"
   - Done! ✅

2. **Make it Public:**
   - Click "Share" → "Anyone with the link" → "Viewer" → "Done"

3. **That's it!** The website is already configured to use Google Sheets.

**Monthly Updates:** Just edit the sheet → Save → Refresh website → Done!

---

### Option 2: Keep Excel Format

1. **Setup Google Apps Script** (one-time, 5 minutes):
   - Go to https://script.google.com
   - New Project → Paste code from `GOOGLE_APPS_SCRIPT.js`
   - Deploy → Web app → "Anyone" access
   - Copy Web App URL

2. **Update Config:**
   - Open `src/config/driveConfig.js`
   - Paste URL: `GOOGLE_APPS_SCRIPT_URL: 'YOUR_URL_HERE'`

3. **Done!** ✅

**Monthly Updates:** Edit Excel → Save → Refresh website → Done!
